== Description ==
پاب‌جت دستیار شما در انتشار رپورتاژ آگهی است. در واقع پاب‌جت امکان انتشار خودکار رپورتاژ در زمان برنامه‌ریزی شده را فراهم می‌آورد.

== Installation ==
بعد از نصب و فعال سازی افزونه به منو تنظیمات پاب‌جت مراجعه کنید و توکن اتصال به حساب تریبون خود را وارد کنید و تنظیمات را ذخیره کنید.
